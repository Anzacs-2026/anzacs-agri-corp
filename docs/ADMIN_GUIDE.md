# Admin Guide — ANZ Agricrop website

For the site owner. No coding knowledge needed for anything in this guide.

## Logging in

Go to `https://<your-site>/admin/login` and sign in with the email and
password given to you when the site launched. There is no self-service
sign-up — only one owner account exists, set up manually for you.

## Products

- **Add a product:** Admin → Products → Add. Fill in name, category,
  description and specs, upload a photo, save.
- **Edit a product:** click any product in the list, change what's needed,
  save.
- **Hide a product without deleting it:** toggle "Visible" off. It
  disappears from the public site immediately but stays in the admin list
  so you can turn it back on any time.
- **Delete a product:** click Delete. It disappears from the public site
  right away. **We keep a copy for 30 days** — if you delete something by
  mistake, contact support within 30 days and we can bring it back. After
  30 days it may not be recoverable.

## Photos

Upload photos in Admin → Photos. Phone photos (4–8MB) are fine as-is — the
site resizes them automatically, you don't need to edit them first.

## Home / About / Contact text

Admin → Pages lets you edit the text blocks on these three pages directly.
Changes go live as soon as you save.

## Enquiries

Every message a visitor sends through the Contact form or product enquiry
button lands in Admin → Enquiries — even if, rarely, the email notification
to your inbox doesn't go through. Check this list, not just your inbox, if
you're ever unsure whether a lead came in. Mark each one New / In Progress
/ Done as you work through it. Export to Excel any time from this page.

## Testimonials

Admin → Testimonials, same add/edit/delete pattern as Products. There's a
single on/off switch (Admin → Settings) that shows or hides the entire
testimonials section on the public site without deleting anything.

## Contact details & WhatsApp number

Admin → Settings holds the phone number, WhatsApp number, address and the
email address enquiry notifications are sent to. Update these any time
without needing a developer.

## If something looks wrong

Contact support with what you were doing and, if possible, a screenshot.
Backend errors are logged automatically — support can look them up without
needing you to reproduce the issue.
